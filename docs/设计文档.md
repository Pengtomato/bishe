# 规模化养殖环境/视频远程监控平台 - 设计文档

## 1. 系统架构

### 1.1 整体架构
本系统采用前后端分离的架构设计，前端使用Vue 3框架，后端使用Spring Boot框架，数据库使用MySQL/H2数据库。系统采用RESTful API进行前后端通信，支持跨平台访问。

### 1.2 技术栈
#### 前端技术栈
- **框架**：Vue 3 + Vite
- **UI组件库**：Element Plus
- **图表库**：ECharts
- **HTTP客户端**：Axios
- **路由管理**：Vue Router
- **状态管理**：Vue 3 Composition API
- **构建工具**：Vite
- **包管理器**：npm

#### 后端技术栈
- **框架**：Spring Boot 2.7.18
- **数据库**：MySQL 8.0 / H2（开发环境）
- **ORM框架**：Spring Data JPA / Hibernate
- **REST API**：Spring Web
- **安全框架**：Spring Security
- **构建工具**：Maven
- **JDK版本**：Java 11

#### 数据库设计
- **关系型数据库**：MySQL 8.0
- **开发数据库**：H2内存数据库
- **数据持久化**：Spring Data JPA
- **事务管理**：Spring Transaction
- **缓存机制**：Spring Cache

## 2. 数据库设计

### 2.1 数据库表结构

#### 2.1.1 用户表（users）
```sql
CREATE TABLE users (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    username VARCHAR(50) NOT NULL UNIQUE,
    password VARCHAR(255) NOT NULL,
    nickname VARCHAR(50),
    email VARCHAR(100),
    phone VARCHAR(20),
    age INTEGER,
    gender VARCHAR(10),
    role VARCHAR(20) NOT NULL,
    create_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    update_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```

**字段说明**：
- id：用户唯一标识
- username：用户名，唯一索引
- password：加密后的密码
- nickname：用户昵称
- email：用户邮箱
- phone：用户电话
- age：用户年龄
- gender：用户性别
- role：用户角色（admin/user）
- create_time：创建时间
- update_time：更新时间

#### 2.1.2 环境数据表（environment_data）
```sql
CREATE TABLE environment_data (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    device_id VARCHAR(50) NOT NULL,
    temperature DECIMAL(5,2),
    humidity DECIMAL(5,2),
    co2 DECIMAL(10,2),
    ammonia DECIMAL(10,2),
    light_intensity DECIMAL(10,2),
    timestamp TIMESTAMP NOT NULL,
    create_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

**字段说明**：
- id：数据唯一标识
- device_id：设备ID
- temperature：温度（℃）
- humidity：湿度（%）
- co2：CO2浓度
- ammonia：氨气浓度
- light_intensity：光照强度
- timestamp：采集时间
- create_time：创建时间

#### 2.1.3 视频监控表（video_monitors）
```sql
CREATE TABLE video_monitors (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    device_id VARCHAR(50) NOT NULL,
    name VARCHAR(100),
    location VARCHAR(100),
    status VARCHAR(20),
    url VARCHAR(500),
    create_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    update_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```

**字段说明**：
- id：监控唯一标识
- device_id：设备ID
- name：监控名称
- location：监控位置
- status：监控状态（在线/离线）
- url：视频流URL
- create_time：创建时间
- update_time：更新时间

#### 2.1.4 预警信息表（alerts）
```sql
CREATE TABLE alerts (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    type VARCHAR(50) NOT NULL,
    level VARCHAR(20) NOT NULL,
    message VARCHAR(500),
    status VARCHAR(20) NOT NULL,
    timestamp TIMESTAMP NOT NULL,
    create_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    update_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```

**字段说明**：
- id：预警唯一标识
- type：预警类型
- level：预警级别（低/中/高/紧急）
- message：预警消息
- status：处理状态（未处理/已处理/已忽略）
- timestamp：预警时间
- create_time：创建时间
- update_time：更新时间

#### 2.1.5 设备信息表（devices）
```sql
CREATE TABLE devices (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(100) NOT NULL,
    type VARCHAR(50),
    status VARCHAR(20),
    location VARCHAR(100),
    create_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    update_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```

**字段说明**：
- id：设备唯一标识
- name：设备名称
- type：设备类型
- status：设备状态（运行/停止/故障）
- location：设备位置
- create_time：创建时间
- update_time：更新时间

### 2.2 数据库索引设计
```sql
-- 用户表索引
CREATE INDEX idx_users_username ON users(username);
CREATE INDEX idx_users_role ON users(role);

-- 环境数据表索引
CREATE INDEX idx_environment_device_id ON environment_data(device_id);
CREATE INDEX idx_environment_timestamp ON environment_data(timestamp);

-- 视频监控表索引
CREATE INDEX idx_video_device_id ON video_monitors(device_id);
CREATE INDEX idx_video_status ON video_monitors(status);

-- 预警信息表索引
CREATE INDEX idx_alert_type ON alerts(type);
CREATE INDEX idx_alert_level ON alerts(level);
CREATE INDEX idx_alert_status ON alerts(status);
CREATE INDEX idx_alert_timestamp ON alerts(timestamp);

-- 设备信息表索引
CREATE INDEX idx_device_type ON devices(type);
CREATE INDEX idx_device_status ON devices(status);
```

### 2.3 数据库关系设计
- 用户与设备：一对多关系
- 设备与环境数据：一对多关系
- 设备与视频监控：一对一关系
- 预警信息：独立实体，关联设备

#### 3.2.2 API接口列表

- GET /api/users - 获取所有用户
- GET /api/users/{id} - 获取指定用户
- POST /api/users - 创建用户
- PUT /api/users/{id} - 更新用户
- DELETE /api/users/{id} - 删除用户

**环境数据API**：
- GET /api/environment - 获取所有环境数据
- GET /api/environment/{id} - 获取指定环境数据
- GET /api/environment/device/{deviceId} - 按设备ID获取数据
- POST /api/environment - 创建环境数据
- PUT /api/environment/{id} - 更新环境数据
- DELETE /api/environment/{id} - 删除环境数据

**视频监控API**：
- GET /api/video - 获取所有视频监控
- GET /api/video/{id} - 获取指定视频监控
- POST /api/video - 创建视频监控
- PUT /api/video/{id} - 更新视频监控
- DELETE /api/video/{id} - 删除视频监控

**预警管理API**：
- GET /api/alerts - 获取所有预警
- GET /api/alerts/{id} - 获取指定预警
- POST /api/alerts - 创建预警
- PUT /api/alerts/{id} - 更新预警
- DELETE /api/alerts/{id} - 删除预警

**设备管理API**：
- GET /api/devices - 获取所有设备
- GET /api/devices/{id} - 获取指定设备
- POST /api/devices - 创建设备
- PUT /api/devices/{id} - 更新设备
- DELETE /api/devices/{id} - 删除设备
