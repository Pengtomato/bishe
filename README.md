# 规模化养殖环境/视频远程监控平台

## 项目简介

本项目是一个基于Spring Boot和Vue 3的现代化养殖环境监控平台，实现了环境数据监测、视频远程监控、智能预警管理、设备远程控制等功能。系统采用前后端分离架构，支持多用户权限管理，提供数据可视化和报表分析功能。

## 技术栈

### 前端技术
- **框架**：Vue 3 + Vite
- **UI组件库**：Element Plus
- **图表库**：ECharts
- **HTTP客户端**：Axios
- **路由管理**：Vue Router
- **状态管理**：Vue 3 Composition API

### 后端技术
- **框架**：Spring Boot 2.7.18
- **数据库**：MySQL 8.0 / H2（开发环境）
- **ORM框架**：Spring Data JPA / Hibernate
- **REST API**：Spring Web
- **构建工具**：Maven
- **JDK版本**：Java 11

## 快速开始

### 环境要求
- JDK 11+
- Node.js 16+
- Maven 3.6+
- MySQL 8.0（可选，开发环境使用H2）

### 后端启动
```bash
# 进入项目根目录
cd d:\javaio\bishe

# 使用Maven编译和运行
& "D:\EDGE\apache-maven-3.9.13-bin\apache-maven-3.9.13\bin\mvn.cmd" spring-boot:run

# 或者在IDE中运行BisheApplication.java
```

后端服务将在 `http://localhost:8080` 启动

### 前端启动
```bash
# 进入前端目录
cd d:\javaio\bishe\frontend

# 安装依赖（首次运行）
npm install

# 启动开发服务器
npm run dev
```

前端服务将在 `http://localhost:3002` 启动

### 访问系统
- 前端地址：http://localhost:3002
- 后端API：http://localhost:8080
- H2控制台：http://localhost:8080/h2-console

## API接口

### 用户管理
- `GET /api/users` - 获取所有用户
- `POST /api/users` - 创建用户
- `PUT /api/users/{id}` - 更新用户
- `DELETE /api/users/{id}` - 删除用户

### 环境数据
- `GET /api/environment` - 获取所有环境数据
- `POST /api/environment` - 创建环境数据
- `PUT /api/environment/{id}` - 更新环境数据

## 常见问题

### 1. 后端启动失败
- 检查JDK版本是否为11+
- 检查Maven配置是否正确
- 检查端口8080是否被占用

### 2. 前端启动失败
- 检查Node.js版本是否为16+
- 检查依赖是否安装完整
- 检查端口3002是否被占用

### 3. 数据库连接失败
- 开发环境使用H2内存数据库，无需配置
- 生产环境需要配置MySQL连接
- 检查数据库服务是否启动

### 4. 登录失败
- 检查用户名和密码是否正确
- 检查后端服务是否正常运行
- 检查网络连接是否正常
